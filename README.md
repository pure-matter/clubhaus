# Clubhaus

A community library and learning hub in The Gambia. This repo holds the website, the brand, and public documents.

- **Site:** `index.html`, `join.html`
- **Content:** `data.json` (progress bars, parts, Tally form, contact links)
- **Docs:** `docs/`

## Brand

| | |
|---|---|
| Blue | `#2340FF` |
| Orange | `#FF6B1F` |
| Ink | `#121212` |
| Paper | `#F5F4F0` |

- **Type:** Bricolage Grotesque, extra bold and narrow for headings, regular for body text. DM Mono for small labels.
- **Overprint:** the wordmark in orange, repeated in blue, shifted slightly down and right, with the overlap printed dark.
